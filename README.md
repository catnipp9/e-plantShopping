# e-plantShopping - Paradise Nursery

Welcome to **e-plantShopping**, the official front-end application for **Paradise Nursery**. This project is a React-based shopping application where users can browse a curated selection of houseplants, learn about our company, and manage a digital shopping cart.

## 🌿 Project Overview
Paradise Nursery is a one-stop shop for high-quality indoor plants. This application is designed to provide a seamless user experience, from a welcoming landing page to a fully functional shopping cart.

## ✨ Features
- **Landing Page:** A beautiful, responsive entry point with a background image, company mission statement, and a "Get Started" button.
- **Product Listing:** - Over 6 unique houseplants organized into 3 distinct categories (Air Purifying, Aromatic, and Low Maintenance).
  - "Add to Cart" functionality that updates the global state and disables the button once an item is added.
  - A dynamic Navbar that displays the total number of items in the cart at all times.
- **Shopping Cart:**
  - View all selected plants with their thumbnails, names, and unit prices.
  - Dynamically update quantities (Increase/Decrease) with real-time total cost calculation.
  - Remove items entirely from the cart using the delete functionality.
  - "Continue Shopping" navigation to return to the nursery.
  - "Coming Soon" checkout integration.

## 🛠️ Tech Stack
- **React:** Component-based UI architecture.
- **Redux Toolkit:** Centralized state management for the shopping cart.
- **Vite:** High-performance build tool and development server.
- **GitHub Pages:** Live deployment of the application.
